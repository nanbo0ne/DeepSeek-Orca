# DeepSeek-Orca V2.0.22

DeepSeek-Orca 是基于 Reasonix fork 改造的 Windows 桌面端与 CLI AI 编程 Agent。它保留核心 Agent 循环、工具调用、MCP、Skill、记忆、权限控制、会话恢复、检查点、上下文压缩和回滚能力，并围绕 DeepSeek / OpenAI-compatible provider 做了桌面端体验增强。

更新记录不再写入 README，已集中保存到 [DESKTOP_CHANGELOG.md](DESKTOP_CHANGELOG.md)。

## 适合做什么

DeepSeek-Orca 面向本地开发、长任务协作和桌面端 AI 工作流：

- 在项目工作区中阅读、修改、测试和回滚代码。
- 管理多轮对话、独立工作区、固定主题、历史记录和回收站。
- 使用 MCP、Skill、记忆文件、CodeGraph 和斜杠菜单扩展能力。
- 通过审批模式控制工具权限，在安全和效率之间切换。
- 使用工具库进行联网搜索、主机命令、进程管理、运行时验证和文档提取。
- 在长上下文中通过压缩、摘要和长期对话检索找回旧信息。

## 三种模式

右下角模式菜单提供三种提示词模式：

- 助手模式：面向日常问答、闲聊、轻量帮助和一般解释。该模式以 `Orca` 身份运行，并只读取助手模式记忆。
- 普通模式：面向常规对话、查询、普通开发任务和较轻量的工程协作。该模式以 `DeepSeek-Orca` 身份运行。
- 增强模式：面向复杂代码、长任务、高质量推理、架构分析、代码审查和 agentic coding。该模式以 `DeepSeek-Orca` 身份运行，可能消耗更多 token。

普通模式和增强模式会读取所有记忆，但写入普通/增强共享记忆。助手模式只读写助手模式记忆，避免日常助手偏好污染工程 Agent 行为。

## 工作区与会话

DeepSeek-Orca 支持项目工作区和独立工作区：

- 项目工作区绑定到真实代码目录，适合长期开发和仓库任务。
- 独立工作区适合临时对话、实验和不想污染项目目录的任务。
- 独立工作区中的每个对话都有自己的小工作区目录，文件、附件、配置、记忆、工具 cwd 和会话目录不会与其他独立对话串线。
- 新对话会继承最近实际对话使用的模型、思考强度、审批力度和模式；临时协作选项默认关闭。

## 工具库

DeepSeek-Orca 默认启用宿主工具库，并允许在“工具库”面板中按组开关。关闭某一组后，该组专用工具不会暴露给模型，工具路由提示词中也不会继续推荐它。

主要工具组包括：

- 系统/主机工具：原生命令、系统信息、进程列表、结束进程、启动应用、剪贴板和通知。
- 联网搜索：不知道具体 URL 时使用 `web_search`，已有 URL 时使用 `web_fetch`。
- Node / Python 运行时：用于脚本验证、数据处理、依赖探测和结构化输出。
- 文档工具：Word / PPT / Excel / PDF 的基础检查与文本提取。
- 线程管理：查看本地 DeepSeek-Orca 会话主题。
- 长期对话检索：压缩后按需搜索更早的本地对话，再读取附近上下文。

当前不包含截图识图、OCR、坐标点击、键盘输入或视觉桌面控制。

## 权限模式

DeepSeek-Orca 使用审批模式控制工具行为：

- 需要批准：高风险或需要确认的工具操作会先询问。
- 自动批准：普通工具权限提示会自动通过，适合信任当前任务时提高效率。
- 完全访问权限：允许工具操作不经额外审批执行，适合你明确希望 Agent 自主完成整套任务的场景。

建议只在你确认任务边界、工作区和风险都可接受时使用完全访问权限。

## 计划、Todo 与侧边聊天

- 复杂任务可以使用自动 Todo，把多阶段工作拆成清单并持续更新状态。
- 计划模式会把待执行计划放进独立计划卡片，用户可以批准执行，也可以要求重新生成完整替代计划。
- 侧边聊天是右侧栏里的只读问答窗口，可以读取当前主对话内容，并重点留意最近几轮上下文。它不会写入主对话历史，也不参与主对话 token 统计、压缩或标题生成。

## 自动化

自动化只用于明确重复性、持续性、后台监控类任务，例如定期检查构建状态、每天固定时间提醒、持续监控日志等。

普通一次性计时需求不会被持久化为自动化。自动化记录保存在本地配置中，应用重启后仍可查看、暂停、恢复、取消或清理。

## 安装后开始使用

1. 运行 Windows 安装包。
2. 启动 DeepSeek-Orca Desktop。
3. 在设置中添加 DeepSeek API Key 或 OpenAI-compatible provider。
4. 从左侧栏创建新对话。
5. 选择项目文件夹或独立工作区。
6. 根据任务需要选择助手模式、普通模式或增强模式。
