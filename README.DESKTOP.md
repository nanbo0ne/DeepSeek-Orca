# DeepSeek-Orca Desktop

DeepSeek-Orca Desktop 是面向图形界面的 AI 编程 Agent。它把模型对话、项目文件、工具调用、上下文统计、回滚记录、MCP/Skill 管理和模型配置放在同一个桌面工作台里，适合在不频繁切换终端的情况下完成代码阅读、修改、调试和项目维护。

## 下载与安装

桌面端用户直接下载打包好的 Windows 安装器即可：`DeepSeek-Orca-Setup-<version>-windows-x64.exe`。

下载后双击安装器，按安装向导选择安装目录并完成安装。桌面端不需要下载源码、npm 包或手动编译。

## How to use

1. 下载最新版 Windows 安装包：[DeepSeek-Orca-Setup-1.0.5-windows-amd64.exe](https://github.com/nanbo0ne/DeepSeek-Orca/releases/download/desktop-v1.0.5/DeepSeek-Orca-Setup-1.0.5-windows-amd64.exe)。
2. 双击安装包，阅读并同意安装协议，选择安装目录，然后完成安装。
3. 启动 DeepSeek-Orca Desktop，在设置中填写 DeepSeek API Key 或配置 OpenAI 兼容 provider。
4. 点击左侧的新建会话，选择进入项目文件夹或使用独立工作区。
5. 在底部输入框描述任务，例如“解释这个项目的架构”或“修复当前测试失败”。
6. 根据任务风险选择权限模式；复杂修改建议先打开 Plan 模式，确认方案后再执行。
7. 如果不满意某次 AI 修改，可以在对应回复上使用回滚或分叉会话。

## 核心定位

DeepSeek-Orca Desktop 不是普通聊天窗口，而是一个可操作项目文件的编程工作台。它可以读取项目结构、解释代码、调用工具、修改文件、运行命令、记录会话、管理上下文，并在需要时回滚 AI 造成的改动。

桌面端适合：

- 在一个或多个项目中长期使用 AI 协助开发。
- 让 AI 阅读代码、解释架构、定位 bug、修改文件。
- 通过按钮、面板和设置完成模型、权限、MCP、Skill 和记忆管理。
- 希望看到工作流细节，但不希望工具调用和推理过程占满对话的人。
- 不熟悉命令行，或者希望用更直观的方式管理会话和上下文的人。

## 主界面

桌面端由左侧工作区栏、中间对话区、底部输入器和右侧上下文面板组成。

左侧栏用于管理会话。会话按置顶、项目工作区、独立工作区分组。置顶只影响展示顺序，不改变会话所属项目。项目会话会归入对应项目文件夹，未绑定项目的会话会归入独立工作区。

中间区域用于对话和工作流展示。用户消息、AI 最终回复、文件变更卡片会保持可读；思考过程、工具调用、工具结果、后台任务、审批和 checkpoint 等工作流消息默认折叠成一行，需要时可以展开查看。

底部输入器用于提交任务。它支持普通文本、slash command、文件引用、目录引用、附件、图片、模型选择、思考强度选择、权限模式和 Plan 模式。

右侧面板用于查看当前会话的上下文、项目文件、文件改动和读取记录。上下文窗口以横条展示，包含 prompt、completion、reasoning、other、总 tokens、压缩阈值、请求数、耗时、缓存命中、费用和读取文件等信息。

## 会话与工作区

DeepSeek-Orca Desktop 支持多会话、多项目和独立工作区。

- 可以同时打开多个会话标签。
- 新建会话时可以选择进入项目或使用独立工作区。
- 项目会话会绑定项目路径，方便按项目归档。
- 独立工作区适合临时问答、跨项目咨询或不需要文件上下文的任务。
- 会话会保存标题、更新时间、轮次、预览和所属工作区。
- 历史记录可恢复，删除后的会话可进入回收站。
- 会话列表支持搜索、重命名、置顶和按项目浏览。

## 对话能力

DeepSeek-Orca 可以进行普通问答，也可以执行代码任务。

常见任务包括：

- 阅读项目结构并总结模块职责。
- 解释某个文件、函数、接口或调用链。
- 根据报错日志定位问题。
- 修改代码、配置、文档和测试。
- 生成测试、补充类型、调整 UI、修复构建错误。
- 审查 Git diff，指出 bug、风险和缺失测试。
- 总结最近改动、生成发布说明、整理待办。
- 在项目中搜索符号、文件、文本和依赖关系。

## 输入器

输入器支持面向编程任务的快捷能力。

- `/` 调用 slash command。
- `@` 引用文件或目录。
- `!` 触发 shell 相关输入。
- `+` 打开二级菜单，用于上传文件、上传图片、引用文件/目录、选择命令和切换 Plan 模式。
- 可切换模型。
- 可切换思考强度。
- 可切换权限模式。
- 可显示附件预览。
- 可在运行中停止任务。

## 权限模式

桌面端提供三种权限模式，控制 Agent 执行工具和写入文件时的自由度。

- Review：更谨慎，适合审查、探索和不确定任务。
- Auto：常规自动模式，适合日常代码修改。
- YOLO：更激进，适合明确知道风险且希望减少确认步骤的任务。

权限模式与 Plan 模式相互独立。可以在 Auto 或 YOLO 下开启 Plan，也可以在 Review 下关闭 Plan。

## Plan 模式

Plan 模式用于让 Agent 先规划再执行。它适合复杂任务、跨文件修改、重构、迁移、UI 改造、测试策略不明确的问题和风险较高的写操作。

Plan 模式开启后，Agent 会更倾向于先说明目标、步骤、影响范围和潜在风险，再进入执行。用户可以先审查方案，再决定是否继续。

## 回滚与 checkpoint

DeepSeek-Orca Desktop 具备会话与文件回滚能力。

- AI 修改文件前会记录 checkpoint。
- 一个 AI 回复内的文件改动会作为同一轮事务处理。
- 可以对对话进行回滚。
- 可以对代码改动进行回滚。
- 可以同时回滚对话和代码。
- 可以从某一轮分叉出新会话。
- 可以从某一轮生成总结。
- 如果回滚后删除了对话内容，token 统计会同步刷新。
- 如果目标文件在 AI 修改后又被用户手动改动，回滚会避免盲目覆盖。

回滚适合在 AI 修改方向不对、误删内容、测试失败或想回到某个讨论节点时使用。

## 文件与项目面板

右侧文件面板可以浏览项目目录。它用于辅助理解当前工作区，让用户看到 Agent 所处的文件环境。

文件能力包括：

- 展示项目文件树。
- 搜索和过滤文件。
- 查看当前会话读取过的文件。
- 查看文件改动记录。
- 展示依赖文件和读取记录。
- 配合 `@` 引用文件或目录作为上下文。

## 上下文统计

上下文面板用于观察当前会话对模型窗口的占用情况。

它会显示：

- 当前上下文 tokens。
- 最大上下文窗口。
- prompt tokens。
- completion tokens。
- reasoning tokens。
- other tokens。
- 压缩阈值。
- 请求数。
- 会话 tokens。
- 运行耗时。
- 缓存命中和本次费用。
- 当前上下文状态。
- 读取文件数量。

这些信息可以帮助判断是否需要压缩、是否需要新开会话、是否有过多无关文件进入上下文。

## 模型与服务商

桌面端支持 DeepSeek 和 OpenAI 兼容接口形式的模型服务。设置页可以管理模型服务、默认模型、可用模型、API Key、base URL、余额查询 URL 和模型访问状态。

模型相关能力包括：

- 官方 DeepSeek 预设。
- Mimo API 和 Mimo Token Plan 预设。
- 自定义 OpenAI 兼容 provider。
- 默认模型选择。
- 独立规划模型。
- subagent 默认模型。
- subagent effort。
- 模型服务启用/禁用。
- 余额查询和状态栏余额显示。
- API Key 环境变量管理。

## 思考强度

桌面端提供思考强度选择，用于传递给支持该能力的模型服务。对于 DeepSeek 相关模型，思考强度会按模型能力映射为官方支持的调用方式；不支持的模型会退回服务默认行为。

思考强度适合在简单任务和复杂推理任务之间切换。简单问答可以使用 auto 或较低强度；复杂修复、架构分析和多步骤计划可以使用更高强度。

## MCP 管理

DeepSeek-Orca Desktop 可以管理 MCP 服务器和 MCP 工具。

支持能力包括：

- 查看 MCP 服务器列表。
- 查看连接状态和异常。
- 展示工具、提示和资源数量。
- 查看失败原因。
- 重试连接。
- 清理无效配置。
- 添加 MCP 服务器。
- 启用或停用 MCP。
- 管理认证信息。
- 通过安装器安装 MCP 能力。

内置 CodeGraph 也以 MCP 形式提供符号级代码理解工具。

## Skill 管理

Skill 是可复用的任务 playbook。桌面端可以查看、搜索、启用、停用和管理 Skill 来源。

Skill 类型包括：

- 内置 Skill。
- 项目 Skill。
- 自定义 Skill。
- 独立工作区 Skill。
- 内联 Skill。
- subagent Skill。

内置 Skill 包括项目探索、资料研究、代码审查、安全审查、测试修复、初始化项目记忆和安装能力等。

## CodeGraph

CodeGraph 是内置代码智能能力，用于符号级搜索、调用关系、影响分析和项目结构理解。

它提供的能力包括：

- 符号搜索。
- 上下文聚合。
- 调用方与被调用方分析。
- 改动影响分析。
- 调用路径追踪。
- 文件树与符号统计。

桌面安装包可随附 CodeGraph 运行时。安装后 DeepSeek-Orca 会优先使用程序目录中的 CodeGraph，避免首次启动时临时下载失败。

## 记忆与指令文件

DeepSeek-Orca 支持长期记忆和项目指令文件。

记忆能力包括：

- 保存用户偏好。
- 保存项目约定。
- 保存长期参考信息。
- 查看记忆列表。
- 删除过期记忆。
- 读取 AGENTS.md、DEEPSEEK_ORCA.md、CLAUDE.md 等项目指令。
- 在未来会话中自动带入相关规则。

记忆适合记录团队规范、项目架构、常用命令、代码风格和用户偏好。

## Bot 连接

桌面设置中包含多渠道 Bot 配置，用于连接外部 IM 消息入口。

支持的配置项包括：

- QQ Bot。
- 飞书/Lark Bot。
- 微信 iLink Bot。
- 连接启用状态。
- allowlist。
- token 环境变量。
- webhook 或 websocket 模式。

这些能力用于把 DeepSeek-Orca 的 Agent 能力接入外部消息渠道。

## 外观设置

桌面端支持外观与布局偏好。

包括：

- 深色/浅色主题。
- DeepSeek 风格蓝色强调色。
- 字号设置。
- 字体选择。
- Comic Sans 选项。
- 思考过程默认展开或折叠。
- 关闭窗口时结束程序或后台运行。
- 启动加载界面。

## 数据与安装目录

桌面端会在本地保存会话、项目索引、配置、记忆、插件、缓存和回滚数据。

常见程序文件包括：

- `deepseek-orca-desktop.exe`：桌面端主程序。
- `node.exe`：附带的 Node 运行时。
- `codegraph/`：随安装包携带的 CodeGraph 运行时。
- `uninstall.exe`：卸载程序。
- `uninstall.bat`：兜底卸载脚本。

用户数据会保存在 DeepSeek-Orca 自己的数据目录中，并与其他应用的数据隔离。

项目中包含：

- React 前端。
- Wails 桌面桥接。
- Windows 图标资源。
- Windows 安装器脚本。
- 卸载器脚本。
- WebView2 嵌入构建。
- 安装目录选择。
- 开始菜单和桌面快捷方式。
- 卸载时保留或删除数据的选项。

## 适合的工作流

推荐使用方式：

- 先让 Agent 阅读项目结构。
- 对复杂任务开启 Plan 模式。
- 使用 Review 或 Auto 权限完成日常任务。
- 大范围修改前保持 Git 干净。
- 让 Agent 修改后检查 diff。
- 运行测试或构建验证结果。
- 不满意时使用回滚或分叉会话。
